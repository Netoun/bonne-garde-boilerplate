# Bonne Garde Player

Mobile-first web app for players to join teams, scan QR codes, and complete puzzles.

## Stack

- **Framework**: React Router v7 (SSR/PWA mode)
- **UI**: shadcn/ui + Tailwind CSS
- **State**: Zustand
- **API Client**: Eden Treaty
- **Maps**: React-Leaflet
- **QR Codes**: qrcode
- **Deploy**: Cloudflare Pages

## Getting Started

```bash
# Dev server
bun run dev

# Build
bun run build

# Deploy
bun run deploy
```
