# Bonne Garde Backoffice

Admin dashboard for managing treasure hunts, scenarios, teams, and games.

## Stack

- **Framework**: React Router v7 (SPA mode)
- **UI**: shadcn/ui + Tailwind CSS
- **State**: Zustand
- **API Client**: Eden Treaty
- **Deploy**: Cloudflare Pages

## Getting Started

```bash
# Dev server
bun run dev

# Build
bun run build

# Deploy
bun run deploy
```
